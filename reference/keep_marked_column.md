# Keep column with marked rows

For check\_\*() functions, keep the column that has marked rows and move
to first column or remove the column depending on `keep` flag. *This
function is not exported.*

## Usage

``` r
keep_marked_column(x, column, keep)
```

## Arguments

- x:

  Data set.

- column:

  Name of exclusion column.

- keep:

  Logical indicating whether to keep or remove exclusion column.
